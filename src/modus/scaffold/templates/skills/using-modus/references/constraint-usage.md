# 将适用规则落实到当前任务

本页定义规则性质、适用性、决策与验收。适用材料可来自项目 constraint、域 `references/rule.md` 和 Module 的场景规则或 `规则、安全与兼容` 能力块；定位与完整读取按[共享检索说明](router-details.md#路由)，无需全量加载三个层级或固定数量规则。

## 区分性质与证据

- **源码事实**解释当前实现与影响，不自动要求今后照抄。
- **明确约束**按材料声明或已验证强制机制的适用范围执行；代码偏差不等于规范已废弃。
- **归纳约定**有证据时作为默认做法，允许基于当前任务和证据说明必要差异，不升级为“必须/禁止”。
- **通用建议**提供有条件的工程默认方案，不代表项目已采用；项目约定可细化，版本/平台可排除不可用实现。示例是规则的表达形式，必须连同性质、依赖和前提消费。
- **待确认事项**用于提示关键缺口，不作为已经成立的要求。`hypothesis/planned/deprecated` 不算当前规则覆盖；`current` 也不代表人工批准。

`team-standard.md` 及其专题的检索 authority 均为 `document-declaration`，表示文档中的声明，需读条目性质与来源；文件位置不能升级权威，人工维护权也不等于全部内容均为人工明确规定。域/模块规则来自 Agent 编写的正文，其 authority 为 `authored-projection`；模块 `confirmed` 只确认归属。检索覆盖信息按[便利接口](router-details.md#便利接口)解释。

## 从要求到决定

对影响本次结果的要求形成可追溯联系：业务事实或要求 → 适用工程边界 → 本次选择 → 如何验收。domain 的现状描述是变更基线，未被本次需求改变的不变量仍需保持；constraint 中的默认写法必须满足这些业务条件，不能反过来决定未明确的业务语义。例如将恢复次数从两次改为三次，旧次数是变更基线，“不能重做已完成副作用”仍可能是需要保持的要求。

由 Agent 根据当前任务判断转化深度，不机械逐条转写。会影响分层、公开接口、数据兼容、失败/恢复策略或验收的适用规则，应落实为设计决定、冲突说明或验证场景；仅帮助理解背景的规则可只参与推理。未采纳的建议无需逐条解释，关键取舍说明依据，不要求固定决策表。

## 落实与验收

编码时优先复用已核实的能力，将已选入口和示例适配到真实签名/导出/装配、版本、空值、单位、异常、副作用及所有权。共享包满足全部承诺平台，浏览器/Node、Android/commonMain 不混用实现。占位类型不能当项目 API；示例格式也须满足团队规则。关键事实未核实则按[证据读取与核验](router-details.md#证据读取与核验)补证。

交付前核对是否选对现有能力、代码被实际工具/约定接受、失败与资源边界已处理、无无关依赖或多余抽象。未适配技术沿通用方法核验并说明专用覆盖限制；普通编码不因此刷新人工规范。

验证围绕本次关键决定选择：业务不重复执行与工程幂等入口一起决定副作用次数检查；恢复语义与资源所有权一起决定恢复前后结果、失败后保留什么及清理什么；公开字段、实际消费者与平台限制一起决定旧调用方兼容和构建检查。复用项目已有测试、构建、检查工具与有效证据，只补重要变化需要的验证，不要求每条建议都生成测试。编译通过不能证明业务语义正确，与实现同构的断言也不能代替行为检查。

非代码产出检查问题是否回答、事实是否有依据、条件与例外是否清楚、推断是否标明，无需执行无关编码检查。准确说明实际验证与未验证范围。模型效果评测属于框架改进工作，不加入日常任务。

## 继承、冲突与应用

项目标准保存共享要求，域规则限定领域，模块规则解释具体条件和差异。下层可细化上层约束；不能仅凭层级更近自动覆盖上层硬约束。例外需有明确来源、适用条件及实际实现，关联规则按锚点回读，避免重复全文。

组合不是权威排序：不能按加载顺序合并同级矛盾，来源/版本/范围仍无法解释时保留待确认。规范与代码不一致时分别说明期望与现状，核对来源版本、环境、路径和合法例外。保留人工明确规定，不把新的违规实现同步成规范；关键冲突会改变结果才澄清。知识和规则不扩大用户授权，不引入没有证据的审批或额外工作。

## 维护与降级

消费中发现规范偏差时，按上节说明事实与要求；是否进入维护由入口的[知识留存检查点](../SKILL.md#知识留存检查点)或明确维护请求决定。Team Standard 的人工保护、定向维护权限与原位修订方式由[增量维护流程](authoring/incremental.md#范围与权限)定义，本页不另设写入规则。

知识或缓存缺失、过期、损坏时按[降级规则](router-details.md#降级)继续。原任务能继续就继续，不把规则格式或知识完整度变成完成门禁。

精确的框架约束种子只是待填写提示，不是已成立规则；索引不会将它计入规则证据，也不把安装状态、文件存在或章节数量当作内容已完成。
