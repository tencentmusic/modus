# Java 证据适配

以 Maven/Gradle 子项目、source set 和打包目标识别构建单元；从 Controller、RPC、消息监听、任务、CLI 与 public type 发现入口。核对 Bean 实际装配、DTO/Entity/序列化、代理事务、多数据源、线程池、资源关闭、配置绑定与集成测试。

AOP、反射、运行时代理和生成代码无法静态闭合时，使用装配、启动测试或实际调用方补证；注解存在不证明入口已注册，方法带事务注解也不证明调用经过代理。

枚举取证同时读常量参数、构造函数与字段赋值，再核对实际 `name()`、`getCode()`、序列化值及显示 getter 的调用。`value`、`desc`、`label` 等名称只是定位线索，不能仅凭字段名认定它是中文显示值；源码已有明确中文映射时按[本地化规则](../../framework/localization.md#已定义中文含义的应用)用于业务叙述，保留协议值本身。
