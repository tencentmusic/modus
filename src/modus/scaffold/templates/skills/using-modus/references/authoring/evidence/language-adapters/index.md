# 语言证据适配索引

Language Adapter 只决定如何取得和核验事实；正文目录、标题、Surface 与业务边界由[共享框架](../../framework/index.md)统一定义。按实际构建单元选读；混合项目组合多个适配器，跨语言关系仍须由装配、协议、配置或真实调用方证明。

编码规范从独立的[规范模块索引](../../../../../modus-init/references/constraint-profiles/index.md)选择；本索引与解析注册不承诺规范支持。

所有适配器回答同一组问题：构建与发布图、公开入口、类型与序列化、控制流与副作用、并发/事务/资源生命周期、配置、验证工具链、解析降级边界。
