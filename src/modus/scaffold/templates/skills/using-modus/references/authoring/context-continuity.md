# 上下文保存与恢复

init/reinit 的串行作者与已授权 Domain worker 共用本合同。唯一持久执行依据是原 `modus/.cache/knowledge-authoring/scope-confirmation.md`，schema 与状态见[范围合同](evidence/scope-modeling.md)。检查点保存在原卡正文。

## 压缩前保存什么

根作者每完成一个可恢复单元，原位替换唯一“当前检查点”：当前 K 阶段、Domain/Module、页面/条目、最近完成检查、最早未完成动作。其余信息归入原卡已有部分，保持当前有效值，不追加“以本条为准”的历史指令。保存后按[执行策略](execution-strategy.md#在现有阶段内组织工作)继续。

| 原卡部分 | 恢复所需内容 |
| --- | --- |
| 范围与授权 | 工作流、仓库/成员、完整 Domain/Module 清单及排除项、质量要求、委派授权和保护路径 |
| 证据与事实 | build 实际结果、双摘要或不可用原因、Module ID → 请求/requestedScope、已读来源与核验条件、正文主落点、反证/省略/未决项 |
| 依赖与共享产物 | 协作基线、事实所有者、输入输出/状态映射、完成/恢复责任与消费者；K5 机制/使用者/反例、规则性质与权限；K6 引用的 K4/K5 版本 |
| 文件与验收 | 原 CAS 哈希、已写/已验版本、未知写入、并发变化、未读/未预览章节与 visual id、具体缺陷和下一动作 |

准确事实可压成带来源的短记录，按域、对象或契约组维护；不复制正文、完整工具输出或已保存的规范。不删后续域、未决项或交接关系。worker 按[并行协议](parallel-domain-authoring.md#按依赖分波)报告增量，由根作者保存，不逐单元等待确认。

下一单元无法容纳取证、成文与回读，或已不能准确复述关键条件时，先保存，再缩小单元；完整范围和解释深度不变。计划暂停、压缩或交接前同样保存，不把存档当作结束理由。

## 宿主摘要与上下文容量

能定制摘要时，只保留原卡实际路径、本轮身份和授权、当前阶段/条目、最早未完成动作、已尝试构建、共享基线和待验位置，并注明恢复先实际读卡。不能只记已完成文件数或最后一个域。不能定制摘要或主动刷新时，依靠持续保存与下述恢复；不要求新聊天、subagent 或重新确认已有授权。

## 逐域加载与恢复

接手或上下文丢失后，除定位卡片外，第一项恢复工作是实际读取原卡。摘要、任务消息、会话 ID 或“读过”标记只用于定位，不能证明仍持有内容。同一作者切域、工具失败或取消后，仍完整持有且版本有效的内容直接复用，只补缺失或变化部分。

1. **读卡定位。** 核对本轮身份、完整范围和授权，读取当前检查点及当前单元/共享条目，确定最早未完成动作。工作区用根卡的成员条目，worker 用根作者指定的同一张卡。
2. **恢复证据。** 沿原卡来源和查询映射补读当前单元。机器 context 按[机器合同](evidence/machine-packet.md)核对双摘要与精确范围；实际事实按[场景闭合](evidence/scenario-closure.md)回读方法体、装配、配置、测试和材料。已有证据有效时不重复查询，失效或缺失时定向补证并保留原因，不重跑 build 或调查无关已验模块。
3. **核对正文与写入。** 读取将编辑或引用的本域/跨域主定义及人工材料，首次创建确认不存在。未知写入区分未落盘、已落盘待验与冲突；保留原 CAS 基线，卡片与文件不一致先核对原因，不刷新哈希后覆盖或自动推进状态。
4. **补齐适用规范。** 根据当前动作直接读取对应[阶段入口](index.md#阶段路线)及其条件化细则。只加载本单元将创作、引用或验收的产物合同，完整保留其中条件和例外；仍有效的已读原文复用，不在每次恢复时展开全套框架、六专题及后续阶段。样稿仅在具体表达问题需要时读取。

读取共用[定位、读取与复用](evidence/index.md#定位读取与复用)。范围、证据、正文和规范一致后，执行已定位动作。同域事实可供多个专题复用。K5/K6 以共享产物取代当前域：K5 恢复机制证据、使用者/反例和规范；K6 恢复 K4/K5 验收版本、交接和概览，不强造 Module selector 或重做各域取证。

## 中断与异常

- 本轮原卡存在或用户明确续作时，恢复未完成动作；历史卡不扩大授权。
- 初始调查未建卡即中断时，核对已有构建与调查记录，接续未完成步骤；build 结果不可确认则记录原因并回当前源码，不重跑。
- 应有的原卡丢失、归属/selector 不明或必需规范不可读时，保留成果并说明待恢复信息；不从输出拼装缩小的全 reviewed 卡。
- 发现跳过恢复时，补读实际缺失输入并核对期间修改；worker 交根作者处理差异，不把漏读记作已执行。

恢复本身不重置状态或重写已验正文。只重开变化或未验范围，未知写入、冲突和视觉待验项未解决前保留原卡。
