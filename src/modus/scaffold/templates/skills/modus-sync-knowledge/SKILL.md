# modus-sync-knowledge

这是代码任务确认存在长期知识影响后的静默执行器，不是用户工作流。`using-modus` 初步判定为正向影响后仍先做安全复核：当前任务的实际 diff 决定范围，正文职责决定落点，人工所有权决定权限；不构建或读取初始化 bundle。

1. 复核本轮实际修改、已确认事实和相关完整正文，不接管工作区原有或其他作者的变化。只读、测试/格式、生成物、第三方或无长期语义影响时静默结束，不运行固定命令、不输出 noop。
2. 确认影响后，完整读取[增量维护流程](../using-modus/references/authoring/incremental.md)，按其共享规则调查主定义与消费者、重算受影响案例、原位修订、回读和发布。只维护当前任务实际导致的语义变化。
3. 结构变化只在当前任务已有授权范围内处理，否则留给显式 init/reinit/update。人工约束与业务资料默认保护；实现变化不自动授权改写 Team Standard。
4. 有实际写入时报告结果和剩余缺口。静默不适用于冲突、部分成功或需要处理的规范偏差；不得把未完成的同步当作无影响。

`explicit`、`symbol`、`path-only` 和 `anchorReviewCandidates` 都是定位候选，不能证明覆盖或退役。正文质量、写入保护和未验证项沿用共享流程，不在本入口复制另一套合同。
