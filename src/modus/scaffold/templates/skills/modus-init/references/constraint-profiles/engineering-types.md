# 工程类型的编码差异

先核对启动、装配、生命周期与实际调用，依赖和目录只给候选。这里补充[公共基础](foundation.md)的运行要求，默认均为通用建议；容量、SLA、框架及专用 API 由目标工程确定。类型可以组合，例：桌面应用 + library + worker。现有 Surface 是导航线索，不承担完整规范分类；更细的平台条件记录在执行卡和条目适用范围，无需先扩充机器枚举。

## backend

从协议入口、身份上下文、业务编排到权威写入核验责任层。默认复用已装配的校验、错误映射、服务和数据访问；错误映射不能吞状态冲突。异步受理与最终完成分开。新增内部入口要核对是否绕开 HTTP/RPC 中间件；验证权限、事务提交后失败和依赖超时。

## frontend

从用户事件、状态/store、请求到渲染追踪。默认复用设计系统、client、状态所有者与错误展示；派生值不重复保存，多请求处理旧结果覆盖与卸载清理。校验空态、加载、失败、重复操作、可访问性及租户切换。SSR 与浏览器分别选适用规则，密钥和请求级状态不进入跨请求共享模块。

## mobile

继续细分 Android、iOS 和实际跨平台 target；从页面/应用生命周期、存储封装、同步器、权限与后台调度装配取证。默认复用 repository、平台存储和生命周期 scope，主线程不执行阻塞 I/O；取消页面工作与可靠后台任务分开。检验离线、进程重启、权限拒绝、存储迁移和重复同步。不能因语言相同就把后端池/事务模板搬到客户端。

Android 核验实际 lifecycle/ViewModel/WorkManager/Room 等使用情况及版本；iOS 核验 actor/Task、生命周期和存储机制。未专用适配的平台只给调查与公共建议，不能猜平台 API。Kotlin multiplatform 的 common/platform source set 分别核验。

## desktop

区分 UI、后台工作和进程间通信。默认复用宿主窗口/状态/IPC 与存储封装；IPC 输入验证、UI 线程亲和、文件权限和退出清理由实际框架确定。验证关窗期间任务、多个窗口状态和升级存储；不能把本机进程或 renderer 当作可信调用者。

## cli

从命令注册、参数/env/config 优先级、stdin/stdout/stderr、文件与子进程取证。默认复用参数解析、输出与退出码机制；可机读 stdout 不混入进度日志，错误说明已完成与未完成副作用。验证管道、无交互模式、中断、部分输出和临时文件清理；不要为 CLI 强加服务分层。

## library

从 exports/public API、调用者和兼容承诺取证。默认复用库的错误/类型、资源与扩展机制；生命周期由声明的所有者承担，不在导入时启动线程、读环境或配置全局日志。验证多调用者、并发共享、旧接口、取消与资源移交；宿主政策不升级为库内硬编码。

## worker

从调度/消息准入、执行、持久化、ack/checkpoint、重试到停止取证。默认复用已验证执行器和处理结果模型；有界准入，持久完成后推进确认点。验证拒绝、重复、乱序、部分成功和停机恢复。浏览器 Web Worker、Node worker_threads 和队列消费进程拥有不同 API/内存/退出语义，名称相同不共用实现。

## data

从 source/transform/sink、水位、分区、质量检查与发布取证。默认复用作业的 checkpoint、schema 和幂等输出；区分重放、增量与全量替换。验证迟到数据、分区失败、重跑和原子发布边界，不能把写入成功等同下游可见。

## infrastructure 与 plugin

基础设施先核对 plan/apply、state/锁、秘密与回滚边界，复用受管模块；插件先核对宿主版本、注册、能力协商、隔离和卸载，复用宿主 API。分别验证漂移/失败恢复及重复加载/卸载，未知机制不补造兜底。
