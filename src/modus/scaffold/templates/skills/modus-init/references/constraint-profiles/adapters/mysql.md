# MySQL 适配差异

在真实数据源/驱动与版本确定后选择，MariaDB 不能仅凭协议相似当作同版本 MySQL。公共查询/事务/迁移见[数据库专项](../capabilities/database.md)。

核对引擎、字符集/排序规则、SQL mode、隔离级别、时区、驱动返回行数策略及迁移工具；不能从连接 URL 推断所有表都支持事务。条件更新对“匹配行/实际改变行”的返回行为结合驱动选项验证，影响行数解释要与幂等契约一致。

默认沿当前迁移定义键、审计字段与索引；不要复制任意 AUTO_INCREMENT、tinyint 软删值或固定 varchar 长度。在线 DDL、默认表达式和索引能力按具体版本验证。[MySQL 文档入口](https://dev.mysql.com/doc/)用于选择匹配版本；离线示例不能证明锁、执行计划和生产配置。
