# C 编码入口

按编译标准、目标 ABI/平台、构建宏与链接依赖选择；C 与 C++ 分开，不能套 RAII、异常或 STL。[C/C++ 取证入口](cpp.md)用于定位构建与调用，不表示 C 项目支持 C++ 机制。

通用建议：明确缓冲区长度、终止符、整数范围、指针可空与所有权；复用已有字符串/容器/错误和清理约定，不假设函数名含 safe 就安全。分配、句柄、锁在成功/失败路径对称释放；多资源失败可沿项目 cleanup 标签或统一清理结构，返回值逐一检查。并发共享与原子操作按目标标准和平台能力核验。

验证零长度、截断、溢出、失败分配、部分初始化和重复释放；sanitizer/static analyzer 只有实际启用才记为机制。未知编译器扩展不写成可移植标准。
