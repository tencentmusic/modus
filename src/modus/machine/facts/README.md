# N2 程序事实

本层回答：独立观察器从冻结输入中直接观察到了什么？

| 可以做 | 不得做 |
| --- | --- |
| 运行结构、编译器与规则观察器，输出统一事实封装、诊断与覆盖回执，各提供方独立降级 | 合并相似身份、虚构跨观察器关系或推断能力 |

公开生命周期动词：`observe`。

扩展边界为 `StructuralExtractor`、`CompilerProvider`、`EntryDetector` 与 `BoundaryResolver`，统一通过不可变内置注册表分发。

调用观察身份包含完整源码区间（或提供者已有的稳定结构位置），同起点的链式调用不能合并。Java、Go、Python、TypeScript 与 C++ 提供者均保留结束位置；实现变动随层实现指纹使相关缓存失效。

N2 一次观察规则命中，N3 只绑定其声明归属。Markdown/文本材料保留按顺序编号的章节、表格、围栏、正文及行段；显式标识符与源码候选的关联不代表语义一致。当前不解析 Office、PDF、图像或公式。

原生语法观察器补充 Java、TypeScript 和 Python 的显式类型成员：声明类型、初始化表达式、可选成员、Java 可空注解/明确序列化名与枚举实参。注解从语法节点读取，支持限定名及显式 `value` 字符串，不把注释、初始化字符串或无关注解参数当作注解事实。事实带原始来源，缺少初始化不等于业务默认值；框架映射及运行效果交由作者定向核对。

声明索引保留完整结束行，Java 参数类型直接取语法节点，字段类型包含声明名后的数组维度；C++ 命名空间保留为所属范围。锚点核验消费这些信息，不能把展示签名的截断或修饰符当作声明变化。原生签名展示截断量随观察传到公开记录。
